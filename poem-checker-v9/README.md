# Poem Checker v9

Версия v9 на Kotlin + Jetpack Compose для Android 9+.

## Что добавлено
- отдельная таблица попыток в Room;
- для каждого стиха хранится история последних экзаменов и тренировок;
- добавлен отдельный экран экзамена без подсказок;
- в карточке стиха и прогрессе теперь отображается лучший результат.

## Логика
1. Учебные этапы остаются прежними: первые слова, последние слова, затем без подсказок.
2. После открытия режима без подсказок можно перейти на экран экзамена.
3. Каждая попытка записывается в базу с режимом, процентом, временем и коротким preview распознанного текста.
4. При 90% и выше на экзамене стих считается выученным.

## Ограничения
- пока нет фильтрации попыток по режиму;
- нет отдельной статистики по среднему результату и числу сдач.
