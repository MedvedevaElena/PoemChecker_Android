# Poem Checker

Приложение на Kotlin + Jetpack Compose для Android 9+, помогающее учить стихи наизусть.

Android-проект находится в этой папке. Общая документация и команды сборки: [README проекта](../README.md). Архитектура и известные проблемы: [docs/architecture.md](../docs/architecture.md). Инструкции для AI-ассистентов: [AGENTS.md](../AGENTS.md).

## Логика
1. Введите стих с переносами строк или надиктуйте его построчно. Сохраните стих, чтобы сохранялись прогресс и попытки. После правки текста нажмите «Обновить стих»: до этого попытки остаются только в памяти и не меняют результат для старого текста.
2. Все четыре режима доступны сразу: первые слова строк, последние, первые и последние, без подсказок.
3. При 85% и выше отмечается прохождение режима первых или последних слов. Режим с обоими словами учитывает только историю и лучший результат.
4. При 90% и выше без подсказок стих считается выученным — как на тренировке, так и на отдельном экране экзамена.
5. Для сохранённого стиха попытки записываются в Room: режим, процент, время и первые 120 символов распознанного текста. На экране отображаются последние 20 записей.

## Ограничения
- пока нет фильтрации попыток по режиму;
- нет отдельной статистики по среднему результату и числу сдач.
- распознавание зависит от установленного системного провайдера; работа без интернета не гарантируется;
- дополнительные распознанные слова показываются, но напрямую не снижают процент совпадения;
- реальная работа микрофона и точность распознавания требуют ручной проверки на устройстве.

## Проверки

После рефакторинга прошли debug-сборка, lint без ошибок, 47 JVM-тестов и 9 тестов на эмуляторе Android 14. GitHub Actions запускает сборку, JVM-тесты и lint на Linux; разработку можно продолжать на macOS.

Код разделён на пакеты `domain`, `data`, `speech`, `ui` и `app`. Имя базы `poem_checker_v9.db` сохранено для совместимости с ранее сохранёнными стихами.
